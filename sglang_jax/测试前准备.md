# TP测试前准备指南

## 当前环境状态

根据环境检查，当前环境可能不在TPU上，或者缺少必要的依赖。TP测试需要在TPU环境中进行。

## 测试环境要求

### 1. TPU环境

测试需要在TPU VM上运行，推荐使用：
- **tpu-v6e-4** (4个TPU芯片，支持TP=1,2,4)
- 通过SkyPilot启动TPU开发机

### 2. 依赖安装

在TPU环境中需要安装：

```bash
# 1. 安装JAX (TPU版本)
pip install jax[tpu] -f https://storage.googleapis.com/jax-releases/libtpu_releases.html

# 2. 安装SGLang-JAX
cd /path/to/sglang-jax
pip install -e python/

# 3. 安装bonsai (如果使用bonsai模型定义)
cd /path/to/bonsai
pip install -e .
```

## 启动TPU环境

### 使用SkyPilot

```bash
# 1. 启动TPU开发机
cd /home/gcpuser/AI-sys-groupwork/sglang_jax
sky launch gptoss_tp.yaml -y --use-spot --infra=gcp -i 5 --down

# 2. 登录TPU开发机
ssh ${your_cluster_name}

# 3. 在TPU环境中运行测试
cd /home/gcpuser/sky_workdir/sgl-jax  # 或实际路径
bash run_tp_test.sh 1
```

## 测试步骤

### 在TPU环境中执行

1. **检查环境**
   ```bash
   bash check_test_env.sh
   ```

2. **测试TP=1**
   ```bash
   TP_SIZE=1 bash go_gptoss.sh
   # 或
   bash run_tp_test.sh 1
   ```

3. **测试TP=2**
   ```bash
   TP_SIZE=2 bash go_gptoss.sh
   # 或
   bash run_tp_test.sh 2
   ```

4. **测试TP=4**
   ```bash
   TP_SIZE=4 bash go_gptoss.sh
   # 或
   bash run_tp_test.sh 4
   ```

5. **对比结果**
   ```bash
   python compare_tp_results.py
   ```

## 常见问题

### Q: 当前环境不在TPU上怎么办？

A: 需要使用SkyPilot启动TPU开发机，然后在TPU环境中运行测试。

### Q: 如何确认在TPU环境中？

A: 运行 `python3 -c "import jax; print(jax.devices())"`，应该看到TPU设备。

### Q: 模型在哪里？
