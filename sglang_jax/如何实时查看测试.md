# 如何实时查看TP测试结果

## 快速查看

### 方法1: 使用监控脚本（推荐）

```bash
cd /home/gcpuser/AI-sys-groupwork/sglang_jax
bash 实时监控.sh
```

### 方法2: 直接查看日志

```bash
cd /home/gcpuser/AI-sys-groupwork/sglang_jax

# 查看最新日志
tail -50 tp2_test_realtime.log

# 实时监控（推荐）
tail -f tp2_test_realtime.log

# 只看关键信息
tail -f tp2_test_realtime.log | grep -E '(Loading|Layer|✅|❌|测试|推理|Output|完成)'
```

## 启动新测试

### 后台运行并实时查看

```bash
cd /home/gcpuser/AI-sys-groupwork/sglang_jax
source ~/miniconda3/etc/profile.d/conda.sh
conda activate sglang-jax
export PYTHONPATH=/home/gcpuser/sky_workdir/sglang-jax/python:$PYTHONPATH
export JAX_COMPILATION_CACHE_DIR=/tmp/jit_cache
export PYTHONUNBUFFERED=1

# 启动测试（后台）
TP_SIZE=2 python -u test_tp_bonsai.py 2>&1 | tee tp2_test_realtime.log &

# 实时查看
tail -f tp2_test_realtime.log
```

### 前台运行（直接看到输出）

```bash
cd /home/gcpuser/AI-sys-groupwork/sglang_jax
source ~/miniconda3/etc/profile.d/conda.sh
conda activate sglang-jax
export PYTHONPATH=/home/gcpuser/sky_workdir/sglang-jax/python:$PYTHONPATH
export JAX_COMPILATION_CACHE_DIR=/tmp/jit_cache
export PYTHONUNBUFFERED=1

# 直接运行（可以看到实时输出）
```

## 检查测试状态

```bash
# 检查进程
ps aux | grep test_tp_bonsai

# 查看日志文件
ls -lht tp2_test*.log | head -5

# 查看最新日志
tail -50 $(ls -t tp2_test*.log | head -1)
```

## 关键信息提取

```bash
# 查看加载进度
grep "Loading layer" tp2_test_realtime.log

# 查看成功/失败信息
grep -E "✅|❌" tp2_test_realtime.log

# 查看错误信息
grep -E "Error|Warning|失败" tp2_test_realtime.log

# 查看推理结果
grep -E "推理|Output|测试" tp2_test_realtime.log
```
