# 快速开始指南

## 在新镜像上配置环境

### 一键配置（推荐）

```bash
cd /home/gcpuser/AI-sys-groupwork/sglang_jax
bash setup_tpu_env.sh
```

这个脚本会自动完成所有环境配置，包括：
- 创建conda环境（Python 3.12）
- 安装JAX (TPU版本)
- 安装SGLang-JAX及其依赖
- 验证环境配置

**预计时间**: 10-20分钟（取决于网络速度）

## 运行TP测试

### 激活环境

```bash
source activate_env.sh
```

### 开始测试

```bash
# 测试TP=1
bash run_test_with_conda.sh 1

# 测试TP=2
bash run_test_with_conda.sh 2

# 测试TP=4
bash run_test_with_conda.sh 4
```

## 验证环境

```bash
source activate_env.sh
bash check_test_env.sh
```

应该看到所有检查项都是 ✅

## 注意事项

- ✅ 必须在TPU VM上运行
- ✅ 需要网络连接（访问GitHub和PyPI）
- ✅ 确保有足够磁盘空间（至少50GB）
- ✅ 首次配置需要10-20分钟
