# 内存优化说明

## 已实施的优化

### 1. 分批加载权重 ✅
- **问题**：一次性加载所有层的MXFP4权重需要大量内存
- **解决**：按层加载，处理完一层后释放内存再加载下一层
- **实现**：将MXFP4权重按层分组，逐层处理

### 2. CPU转换 + 直接Shard ✅
- **问题**：在设备上转换MXFP4权重会占用大量设备内存
- **解决**：使用numpy在CPU上完成所有转换，然后直接shard到设备
- **实现**：
  - 所有转换操作在CPU（numpy）上完成
  - 转换完成后，使用`jax.device_put`直接shard到mesh
  - 避免在设备上创建中间大数组

### 3. 及时释放内存 ✅
- **问题**：临时数组占用内存不释放
- **解决**：每处理完一个权重后立即删除临时数组并调用gc.collect()
- **实现**：
  - 使用`del`删除numpy数组
  - 每层处理完后调用`gc.collect()`
  - 权重赋值后立即删除临时tensor

### 4. 非MXFP4权重优化 ✅
- **问题**：非MXFP4权重也占用内存
- **解决**：直接使用numpy加载，然后shard，避免中间JAX数组
- **实现**：
  - 使用numpy加载权重
  - 转换为JAX后立即shard
  - 删除numpy数组

## 优化效果

### 内存使用
- **之前**：需要一次性分配~2GB内存（单层MXFP4权重）
- **现在**：按层处理，每层处理完后释放，峰值内存大幅降低

### 处理流程
1. 加载非MXFP4权重（较小，直接shard）
2. 按层处理MXFP4权重：
   - 加载blocks和scales（numpy）
   - CPU上转换（numpy）
   - 转换为JAX并shard（一步完成）
   - 删除临时数组
   - 继续下一层
